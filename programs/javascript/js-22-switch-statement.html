JavaScript 22

Switch Statement

Runnable JavaScript practical program.

Source Code

let day = 3;
let name;
switch (day) {
  case 1: name = "Monday"; break;
  case 2: name = "Tuesday"; break;
  case 3: name = "Wednesday"; break;
  default: name = "Invalid day";
}
document.getElementById("output").textContent = name;
