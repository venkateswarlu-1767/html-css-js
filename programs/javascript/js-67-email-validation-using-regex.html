Email Validation using Regex

Runnable JavaScript practical program.

Source Code

let email = "student@example.com";
let pattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
document.getElementById("output").textContent =
  `${email} is ${pattern.test(email) ? "Valid" : "Invalid"}`;
